## 安装 cc-switch-cli

> 以ubuntu24.04为例，其他系统请参考[cc-switch-cli官方文档](https://github.com/SaladDay/cc-switch-cli)

```bash
curl -fsSL https://github.com/SaladDay/cc-switch-cli/releases/latest/download/install.sh | bash
```

刷新终端：

```bash
source ~/.bashrc
```

## 运行cc-switch-cli

```bash
cc-switch
```
